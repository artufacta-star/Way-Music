Way Music

Complete source code of a listener-only music streaming app: Expo / React Native client, Node.js API, five open music catalogs and an optional crypto Premium plan.

Watch the demo on YouTube Demo on Google Drive Contact the owner

What the app does

  • Sign-up and login, Home, Feed, Search, Library and Profile
  • Mini and full player, likes, follows, playlists, artist radio, history
  • Charts by country and music by region
  • Free plan with a daily download limit; Premium adds themes, playback speed, sleep timer and stats
  • Rate limiting, signed short-lived media links, secret checks at startup

Where the music comes from

There is no artist upload. Tracks come from Audius, Jamendo, Openverse, ccMixter and the Internet Archive, filtered by licence so only commercially usable tracks are kept.

Premium without a payment processor

Premium costs $3 per month, $8 per 3 months or $20 per year. Users pay in USDT or USDC on Ethereum, BNB Chain or Solana straight to the owner's wallet, and the API verifies the transaction on-chain.

What you get

  • Mobile app, Node.js API and web client source code
  • Docker and Render deployment kit
  • Deployment guide, buyer guide, API and architecture notes
  • Web client screenshots and app icon source files

Honest status

Tested

  • Login, catalog, search and playback in Expo Go on a real Android phone
  • Catalog mappers and region logic (unit tests); web client in a browser against a mock API

Not tested or not included

  • Importers and on-chain payment verification are not verified end to end on live services
  • Jamendo's free API is non-commercial: a commercial launch needs an agreement or that source disabled
  • App Store and Google Play require their own billing, so crypto payments in store builds may be rejected
  • No email verification, password reset, admin web UI, real offline downloads or legal pages

This is source code and documentation, not a running business: no users, revenue, store listing or domain.

Tech stack

TypeScript, Expo, React Native, expo-audio, Node.js, Express, Prisma, PostgreSQL, Docker.
